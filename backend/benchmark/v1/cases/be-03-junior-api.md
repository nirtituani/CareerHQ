Willow Retail Tech is hiring a Junior Backend Developer for our inventory API team.

This is a first or second job. We expect you to arrive able to write code and leave able to own a service. There is a real onboarding plan, a named buddy for your first three months, and nobody will be surprised when you ask a basic question in month five.

The inventory API is nine years old. It is not beautiful. Part of your job will be reading it and asking why, and part of ours will be answering honestly.

What we need:
- One to three years of professional software development. Internships count.
- Any modern backend language. We use Python; we hire people who have used other things.
- Basic SQL: you should be able to write a join and know what an index is for.
- Willingness to work in a large existing codebase rather than starting from scratch.
- Written English good enough to work asynchronously with colleagues in three time zones.

We do not ask for a take-home longer than two hours, and we pay for it.
