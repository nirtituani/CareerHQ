# Judging rubric v1

**Versioned, and a change is a new version.** Every judge score records the rubric
version that produced it, because changing a rubric silently makes every historical
score incomparable — the rule `criteria_version` and `finalisation_rules_version`
already follow.

**This rubric says what each level means. It says nothing about how often each
level should occur.** Telling a model how to distribute its answers is a mistake
this project has already paid for: *"Most real profiles are mostly `partial`…"*
made the model push verdicts down to comply (slice 004). There is no target
distribution here and there must never be one.

**The judge sees the posting, the résumé and this rubric — and nothing else.** Not
the profile (it would become a second Reviewer and its score would correlate with
the Reviewer's by construction), not the plan (it would score intent rather than
result), not the findings (it would echo them), and not which arm produced the
output (it would score the label).

---

## Dimensions

Each is scored **1–5**. A score of 3 is not a failure; it is the honest middle.

### 1. Relevance to the posting

| | |
|---|---|
| **5** | Every prominent claim bears on something the posting asks for. A reader would say the résumé was written for this job. |
| **4** | Mostly targeted; one or two prominent items are generic. |
| **3** | Targeted in places. A reader could tell it was adapted, but much of it would suit any job in the field. |
| **2** | Largely generic, with occasional relevance. |
| **1** | Nothing indicates the writer read the posting. |

### 2. Coverage of stated requirements

Judge against the requirements **the posting states**, weighting those it presents
as essential more heavily. **Absence of evidence is the finding** — if the résumé
does not address a requirement, say so; do not assume it is covered elsewhere.

| | |
|---|---|
| **5** | Every essential requirement is addressed with concrete evidence. |
| **4** | All essential requirements addressed; some thinly. |
| **3** | Most essential requirements addressed; at least one not at all. |
| **2** | Several essential requirements unaddressed. |
| **1** | The résumé does not engage with the requirement list. |

### 3. Specificity of evidence

| | |
|---|---|
| **5** | Claims are concrete: what was done, at what scale, with what result. |
| **4** | Mostly concrete, with some claims that assert rather than show. |
| **3** | A mix of concrete achievement and job-description prose. |
| **2** | Mostly responsibilities rather than achievements. |
| **1** | Assertions with nothing behind them. |

### 4. Plausibility

**This dimension asks whether the document reads as though it might be inflated —
not whether it *is*.** You cannot see the underlying profile, so you cannot know.
What you can judge is whether the claims are internally consistent, proportionate
to the stated seniority and dates, and free of the register that signals
overstatement.

| | |
|---|---|
| **5** | Entirely proportionate. Nothing invites a sceptical question. |
| **4** | Proportionate; one claim a reader might probe. |
| **3** | Some claims are stated more strongly than their supporting detail warrants. |
| **2** | Several claims are disproportionate to the role, the dates or each other. |
| **1** | Internally inconsistent, or claiming scope the timeline cannot support. |

### 5. Presentation

| | |
|---|---|
| **5** | Clear, scannable, consistent. A recruiter finds what they need immediately. |
| **4** | Clear, with minor inconsistency. |
| **3** | Readable but uneven. |
| **2** | Hard to scan; structure fights the reader. |
| **1** | Disorganised. |

---

## What to write

For each dimension: **one sentence** naming the specific thing in the résumé that
decided the score. "Good coverage" is not a justification. "Kubernetes is listed as
a skill but no bullet shows it in use, and the posting calls it essential" is.

## What not to do

- **Do not reward length.** A longer résumé is not a better one.
- **Do not infer facts the résumé does not state**, in either direction.
- **Do not guess which system produced this**, and do not let a guess affect a score.
